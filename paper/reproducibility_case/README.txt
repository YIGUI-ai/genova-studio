GENOVA Studio Reproducibility Case

This package reproduces the balanced P x (I:R) official example using anonymous identifiers.

Files
- anonymous_p_ir_example.csv: 120 input observations
- GENOVA_Studio_Reproducibility_Case.xlsx: input, configuration, expected results, and checks
- expected_anova.csv: expected ANOVA table
- expected_variance_components.csv: expected G-study variance components
- expected_dstudy.csv: expected D-study summary
- analysis_configuration.txt: GUI settings
- GENOVA_Studio_Reproducibility_Tutorial.docx: step-by-step tutorial and interpretation
- official_jgenova_reference_output.txt: full reference engine output

Verification scope
The numerical targets reproduce this official balanced example. They do not establish equivalence for every possible design.
