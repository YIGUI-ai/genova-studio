# Third-party source in GENOVA Studio

`third_party/jGENOVA1.0/src/` contains the unchanged Java source used by the
balanced GENOVA pathway. Joe E. Crick and Robert L. Brennan developed this
component. Their project website publicly supplies the jGENOVA application
and source archive and states that the programs may be distributed freely to
others.

The original source archive contains no standalone SPDX or standard
open-source license. GENOVA Studio therefore does not assign jGENOVA a new
license. The BSD 3-Clause License in `LICENSE.txt` covers only original GENOVA
Studio code and materials and expressly excludes `third_party/jGENOVA1.0/`.
See `THIRD_PARTY_NOTICES.md` for the source URLs, access date, original archive
hash, attribution, and redistribution basis.
